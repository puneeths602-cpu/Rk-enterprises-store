## 📦 Products & Materials Covered
- **Cement:** UltraTech (Super/PPC/OPC), Deccan Cements, Sagar Cements
- **TMT Steel Rebars:** Tata Tiscon 550D, Vizag Steel (RINL), Godavari TMT (8mm, 10mm, 12mm, 16mm, 20mm)
- **MS Structural Steel & Pipes:** MS Round Pipes, MS Square Hollow Sections (SHS/RHS), MS Structural L-Angles
- **GI Pipes (Galvanized Iron):** GI Round Pipes (A, B, C Class), Pre-Galvanized (GP) Square Tubes
- **Roofing Sheets:** JSW Colouron+ Color-Coated Profile Sheets, Jindal Corrugated Galvalume Sheets
- **Plumbing (Hot & Cold):** CPVC Pipes (SDR 11/13.5), Complete CPVC Fittings (T-Shape, Elbows, Couplings, Brass MTA/FTA)
- **PVC & HDPE:** Rigid PVC Agriculture & Drainage Pipes with fittings, HDPE coil pipes with compression joints
- **Garden Pipes:** Multi-layer braided flexible garden water hose coils

---

## ✨ Features
1. **Direct WhatsApp Order Generator:** Pre-fills material item list, quantities, sizes, and site delivery address.
2. **Interactive Size & Gauge Selectors:** Choose exact steel bar diameters (8mm, 10mm, 12mm), pipe gauges, and sheet colors.
3. **Owner Live Price Manager:** Built-in admin panel to change daily cement & steel market rates without editing code.
4. **Site Delivery Logistics Checkout:** Choose between direct tractor/lorry site delivery in Parchur or shop self-pickup.
5. **Printable Invoices:** Generates customer delivery challans with unique order numbers (e.g. `#RK-84920`).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/rk-enterprises-store.git

# Navigate into the folder
cd rk-enterprises-store

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

### Production Build
```bash
npm run build
npm run start
```
